# Сложно сосредоточиться

Адаптивная одностраничная вёрстка по макету из Figma: статья о том, почему сложно сосредоточиться и как с этим справляться. Проектная работа 4 спринта курса «Фронтенд-разработчик» (Яндекс Практикум).

## Что реализовано

- Mobile First: вёрстка проверена на ширинах 375, 768 и 1024 px, ширина контента ограничена 1440 px, горизонтального скролла нет.
- Три темы: «День» (светлая), «Неон» (тёмная) и «Авто» (по системным настройкам). Выбор запоминается в `localStorage`.
- Стили разнесены по файлам: `variables.css` (переменные, значения по умолчанию для тёмной темы), `style.css` (основные стили), `dark.css` и `light.css` (переопределения при выборе темы).
- Сетка на CSS Grid: шапка, карточки статьи и галерея изображений без лишних обёрток.
- Фавиконки для браузеров и иконка для iOS, изображения с `alt` и ленивой загрузкой.
- Названия классов по методологии БЭМ.

## Структура

```
.
├── fonts/        шрифт IBM Plex Mono
├── images/       изображения и иконки
├── scripts/      переключатель темы
├── styles/       стили проекта
└── index.html
```

## Как запустить

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

## Технологии

HTML5, CSS3 (Grid, Flexbox, custom properties, `clamp()`, медиазапросы), JavaScript для переключения темы.
